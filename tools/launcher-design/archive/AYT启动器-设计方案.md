## B. v3「绘世式」（当前设计）—— 参考秋叶绘世启动器

### B.1 返工动因

你要求「找一下秋叶 aaaki 版的 SD 启动器（绘世）做参考再来一版」。v2 是单视图门面（只有一个主动作）；v3 要的是**功能现场**——像绘世那样「功能多但每一处都安静」。答案是那套**行式模板**：所有功能都用同一张「图标 + 标题 + 人话副标题 + 一个控件」的行承载。

### B.2 参考解剖（机制，不是皮）

参考对象：绘世启动器 **v2.8.3**（秋葉aaaki × 喵喵hmkai，.NET 6 WPF，闭源）。
证据链（都是实读，不是印象）：官方生态文档站（licyk/SDNote）仓库内嵌的 **55 张真实截图**（逐张原生看图）× 社区**复刻仓库** `XnneHangLab/HuixinLauncherTemplate`（Tauri+React，"UI 风格参考绘世启动器"，源码逐行读）× 文档文本。完整对照表见 `_ref/aaaki-huishi-dissection.md`。

拿走九条机制：

| # | 绘世机制 | AYT v3 落地 |
|---|---|---|
| 1 | 图标窄栏（图标上/字下；选中=抬升块+左指示条） | 76px 侧栏：一键启动 / 高级选项 / 疑难解答 / 模型管理 / 控制台 + 底部设置 |
| 2 | Hero 横幅 + 双列（左卡网格 / 右面板+底部大按钮）+ 版本行 | 自绘 SVG 画报（管线母题）+ 快捷入口 6 卡 + 状态面板 + 52px「一键启动」 |
| 3 | 单主按钮 | 首页唯一重按钮；控制台条内主按钮随状态换标签（启动/打开/监控） |
| 4 | 控制台=黑底日志；**启动后自动跳控制台** | 同构；日志含时间戳 + 频道色（系统/输出/错误/警告/完成），流式逐行出现 |
| 5 | 设置行模板（图标块+标题+副标题+右控件） | 高级选项与设置两页全量采用；行高 52px、控件右对齐 |
| 6 | 标签条二级导航（活动下划线） | 高级选项（3 子页）/ 模型管理（3 子页）/ 设置（2 子页） |
| 7 | 密集数据表 | 权重页表格（7 行真实文件：名称/位置/大小/日期/mAP/操作） |
| 8 | 新手/专家双模式 | 设置页「配置模式」：新手隐藏 12 个高级项 + 虚线提示行 |
| 9 | 功能词具体（镜像/诊断包/路径覆盖…） | 全部换成本项目真实对应（PyPI/HF 镜像、Python/torch 组件、诊断包、端口） |

**不取**：蓝色系配色、图标画风、公告区、灯泡彩蛋。视觉身份仍是暖石墨 + 鎏金铜 + 瓷白 + 主题系统（深/浅 × 4 强调色）。

### B.4 状态机与联动

| 场景 | 首页 | 控制台 |

| 空环境 | 琥珀横幅「还没有可训练数据集」 | 3 行空态日志 |

## A. v2「门面版」（历史设计）—— 参考 ComfyUI Desktop 的返工

### A.1 返工动因

v1 是「五屏工作台」式设计，信息密度按仪表盘来，元素与文案偏多。v2 换的不是配色，而是**结构**：从「五屏工作台」压回**一个视图的门面**——一个主动作、一个状态机、渐进披露。视觉身份（暖石墨 + 鎏金铜 + 瓷白、主题系统）全部沿用 v1。

### A.2 参考解剖（机制，不是皮）

参考对象是官方 **ComfyUI Desktop v1.0.38**（`F:\Comfy-Desktop\Comfy Desktop\resources\app.asar`；asar 内含未混淆的 Vue 3 源码，完整解剖见 `_ref/comfy-desktop-dissection.md`）。拿走五条机制：

| # | Comfy 机制 | AYT v2 落地 |
|---|---|---|
| 1 | **单视图居中集群**（logo → 字标 → 单主按钮 → 一行安静入口） | 主页同构；五屏导航全部撤掉 |
| 2 | **单主按钮**（最高视觉权重只给一个动作） | `启动控制台`；运行中变 `打开控制台`、训练中变 `打开监控` |
| 3 | **整面接管层做过渡**（检查/启动/错误都接管内容区，不弹对话框） | `#takeover`：启动序列 / 首启自检 / 端口冲突 |
| 4 | **错误 = 一句话 + ≤2 个动作** | 「端口 8080 被占用」→「改用 8081」/「结束占用进程」 |
| 5 | **渐进披露**（瓦片内不放按钮，操作进浮层） | 设置 / 外观 / 场景演示进弹层；功能清单不进首屏 |

**不取**：Comfy 的配色、字体（Inter）、大写字距标签、瓦片网格——那些是 Comfy 的品牌语言。v2 的视觉身份仍完全属于本项目。

## 0. 本轮定位与假设（先说清楚）

- 本轮为 **Auto YOLO Training 项目新增一个「启动器」** 所做的界面设计。启动器 = 项目的**本地门面程序**：负责环境自检、服务启停（控制台 / 推理服务）、资源清点（数据集 / 权重 / 训练记录）、启动训练入口与设置——让使用者不再需要记 `make web`、`ayt-serve`、`ayt-train` 这些命令。
- **视觉从零设计**（依你指示）：不继承旧控制台的蓝/玻璃/几何字形语言。旧控制台仍是项目的工作空间；启动器与它是「门面 vs 工作台」的关系，两者不需要同一张脸。
- 「项目已有资产」= **产品的功能与真实数据**（6 个数据集、27 个模型目录、9 个 CLI 服务、训练流水线、注册表……），原型中的数值均取自仓库实测，不编造。
- 假设：启动器实现形态为一个独立桌面小程序（建议 PyWebView 壳 + 本地 mini 服务，见 §9）。本轮只交付设计稿与原型，不动物理代码。
- 若你所说的「启动器」另有所指（例如整个控制台改版），请直接说——本套视觉系统可以整体平移到控制台场景。

## 1. 产品定调（form 五问）

| 问题 | 答案 |
|---|---|
| **叙事角色** | 门面 / 发车台。一屏完成「能不能训 · 开始什么 · 去哪里」三个决策 |
| **观看距离** | 桌面 60cm，窗口 1280–1600px；正文 13px，读数等宽 |
| **视觉温度** | 冷静、精密、可以久看。像一件**仪器**，不像一块屏幕 |
| **容量估算** | 五屏：启动台 / 服务 / 环境 / 资源 / 设置；首屏只放一个焦点（启动），其余让位 |
| **视觉母题** | **「训练流水线」**——校验 → 配置 → 调参 → 训练 → 评估 → 导出，这是本项目独一无二的结构。它被做成一条贯穿首屏的**工位轨道**，承载「最近一次跑到哪一步」的真实状态；不是贴图 |

**视觉论点（一句话）**：
> 这是一个本地训练台的**发车台**，给需要长时间跑训练的人用，核心动作是**一键把整套环境拉起来**；
> 视觉上用「**暖石墨 + 鎏金铜 + 瓷白**」的仪器语汇——深色分层承载材质，衬线字承载优雅，等宽数字承载精确；
> 母题是**轨道与仪表**：把「能不能训、训到哪一步」变成首屏上真实流动的结构。

## 2. 风格来源与拒绝的理由（反 AI 味）

**参考的是机制，不是皮**（§8 参考解剖法）：

| 参考 | 拿走的机制 |
|---|---|
| 高端仪器面板（Teenage Engineering / 音频设备前面板） | 微标签刻线、方角 LED、等宽读数、金属accent 只用在一处 |
| Linear 暗色 | 文字层级用「亮度和字重」而非颜色；描边极轻；hover 才浮现操作 |
| Braun / 拉姆斯 | 「尽可能少的设计」：删掉一切不携带信息的装饰 |
| 秋叶绘世 / PCL2（机制层） | 启动器三件套：一键启动占最高视觉权重、环境自检说人话、单项可恢复默认 |

**明确拒绝**（12 条速查对照中高危项）：

| 拒绝 | 理由 |
|---|---|
| 紫→蓝渐变、霓虹光晕 | 训练语料最大公约数；且与「精密」无关 |
| 玻璃拟态堆料 | 上一版已用过；模糊在本设计里只在窗口壳最外层出现一次 |
| 三星球/网格/粒子背景 | 装饰不携带信息 |
| emoji 图标 | 全 SVG 细线图标，统一 1.25px 描边 |
| 方框+连线式的「流水线示意图」 | 改成有状态的**轨道**（真实节点、真实状态），不是装饰图 |
| 大数字 KPI 墙 | 每个数字都带单位、量纲和上限（如显存 0.62 / 15.9 GB） |

## 4. 视觉系统

### 4.1 色彩（暖石墨 · 鎏金铜 · 瓷白）

设计意图：**近黑是画布，不是颜色**。表面用四级暖灰度分层表达层级（色调提升），描边只做结构线；整个界面只有一个「有色」来源——铜金，且只出现在交互与「活着」的状态上。

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#131110` | L0 窗口底 |
| `--bg-card` | `#1a1715` | L1 面板（模块、表区） |
| `--bg-raise` | `#231f1a` | L2 抬升（输入、悬停、选中） |
| `--bg-deep` | `#0c0a09` | 凹陷（日志井、进度槽、矩阵底） |
| `--line` / `--line2` | `rgba(244,236,222,.07)` / `.13` | 发丝线 / 结构线 |
| `--ink` | `#f2ece1` | 主文本（瓷白） |
| `--ink2` | `#bdb2a0` | 次要文本 |
| `--ink3` | `#97897a` | 弱文本（全部 ≥4.5:1，已按探针逐项校准） |
| `--brass` | `#c9a35c` | 唯一 accent：主操作、选中、活动状态 |
| `--brass-hi` / `--brass-lo` | `#e9d3a2` / `#8f7136` | 金属渐变两端 |
| `--ok` / `--warn` / `--err` | `#8fb07e` / `#d99a4e` / `#d2766b` | 语义状态（柔化，非荧光；err 已抬亮一档过对比度） |

规则：**同一屏内「有色」元素 ≤ 3 处**（主操作 / 活动状态 / 一处语义提示）；其余全部靠明度与排版。实测像素级铜金占比 ≤0.5%（首页 0.47%）。

### 4.2 字体（本版的核心杠杆）

| 角色 | 字体 | 说明 |
|---|---|---|
| 展示衬线（拉丁） | **Instrument Serif** 400 | 品牌字标、大标题的「优雅」来源；高对比现代衬线 |
| 展示衬线（中文） | **Noto Serif SC** 400 | 中文标题与品牌语；与 Instrument Serif 同气质 |
| 界面无衬线 | **Instrument Sans Variable** + **Noto Sans SC** 400/500 | 正文、按钮、表格；拉丁用可变字重（440/500/540 档生效） |
| 数据等宽 | **IBM Plex Mono** 400/500 | 指标、端口、路径、日志、时间戳；仪器读数感 |

字号档（**5 档**，实测收敛）：`12 / 13 / 16 / 26 / 30`
- **12 = 副档**：微标签、等宽次读数、辅助注释（信息密集屏主导 51–60%；字距 +0.06~0.14em，仅拉丁）；
- **13 = 主档**：正文 / 表格 / 控件 / 按钮（内容型屏主导 74–80%）；
- 16 = 模块标题；26 = 页面标题；30 = 主控状态字（展示档）。

数字全部 `tabular-nums`。

> **两个已踩实的坑（已修复，写进交付备注）**：
> ① 可变字重包的字族名是 **`Instrument Sans Variable`**，CSS 里写 `"Instrument Sans"` 会**静默回退**成系统字体——本版已改对；
> ② 字体**已完整本地化**到 `fonts/`（317 个 woff2 切片，8.2 MB，来源 Fontsource），原型**离线可用**，不再依赖任何 CDN。整包文件夹一起移动即可。

### 4.3 材质与光

- **一束光**：窗口左上角极淡的暖色光斑（`radial-gradient`，峰值 ≈3% 白），是「光从上方来」的唯一来源——让近黑读成有厚度的面。
- **两种阴影上限**：面板静置无阴影（靠色阶分层）；浮层一档 `0 24px 60px -30px rgba(0,0,0,.85)`。
- **窗口壳**：模拟 Mica 的双层（底色 + 10% 白叠加），不使用 backdrop-filter（性能与质感双赢）。
- **元素级渐变仅 3 处**（桌面光 / 窗口壳受光 / 鎏金主按钮），其余全部平色——实测已收敛。
- 圆角（**3 档**，实测收敛）：`0`（LED / 刻痕 / 分节条）· `10`（面板、按钮、输入、主控模块）· `999`（状态胶囊）。

### 4.4 图标

全部为手写细线 SVG（1.25px、圆头、16px 网格）：启动、服务、仪表、资源、滑杆、文件夹、下载、刷新、检查环、外链、停止、箭头。**不使用 emoji、不使用几何字符拼图**。

### 4.5 布局骨架

- 窗口 **1400 × 880**（min 1024 × 680），标题栏 44px，左轨 232px，页面内边距 36px。
- 首屏读作**一个构图**：主控模块（大）＋ 就绪仪表（同模块右列）为一组焦点；轨道、最近训练、快速开始为次级层。
- 网格 12 列、间距 8px 节奏；区块之间用「刻线微标签」分隔（`———— 最近训练 ————` 的仪器刻字感），而不是给每块加卡片边框。

### 4.6 主题系统（v1.1 新增）

**形态**：模式 × 强调色 的正交组合，全部存本地（`localStorage`）。
- **模式**：深色（暖石墨）/ 浅色（瓷白纸面）/ 跟随系统（`prefers-color-scheme` 实时联动）。
- **强调色**：鎏金（默认）/ 青瓷 / 靛蓝 / 砚墨 四套预设 + **自定义取色**（原生取色器；文字用色按对比度自动求解，≥4.5:1 才落地）。
- **深/浅两套值域**：accent 浅色版整体加深，且**填充与文字两个字位分离**（如鎏金填充 `#b08a3e` / 文字 `#775a18`）；语义色（ok/warn/err）浅色版逐项过 4.5:1 校准。

**工程做法（token 化，非覆盖式）**：把颜色字面量收成「可换底的 α 值」：白色抬升 `rgba(var(--lift-rgb),α)`、强调色 `rgba(var(--acc-rgb),α)`。深色 `--lift-rgb:255,244,225` / 浅色 `74,58,38`，一处翻面、几十处悬停底/发丝线/抬升面整体切换；黑阴影深浅不可共享 α，单独成组（`--win-shadow / --sh-float / --inset-*`）。预置脚本先于样式执行（localStorage → 属性 → 默认），无闪烁；切换瞬间 220ms 颜色过渡（reduced-motion 关闭）。

**入口**：标题栏「外观」弹层（快捷切换）+ 设置页「外观」组（完整版）。主题展示截图见 `shots/theme/`。

## 5. 签名元素（拿掉它信息就有损）

1. **主控模块**（启动台焦点）：仪器式启停面板。左侧状态字（衬线）+ 启动按钮 + 启动时的**分阶段序列**（准备环境 → 校验构建产物 → 绑定端口 → 就绪），右侧就绪仪表。启动过程是被**编舞**的，不是一根进度条。
2. **流水线轨道**：六个工位（校验/配置/调参/训练/评估/导出）横向排列，每个工位一枚方角 LED 与微标签；最近一次训练的进度从这里流过，点工位可跳到训练记录。它是产品的解剖图，也是导航。
3. **就绪仪表**：环境 / 设备 / 显存 / 磁盘 / 数据集 五项，左微标签、右等宽读数、行尾 LED；显存用分段刻度条。回答「现在能不能训」。
4. **刻线微标签**：区块之间以「发丝线＋居中小字」分隔，制造仪器前面板的刻字感；全屏 ≤4 处，多了就俗。

## 6. 交互与动效

**原则**：动效承载状态变化；频率高的操作（导航、悬停）几乎不动；罕见时刻（启动成功、首次引导）才允许「被记住」。

| 时刻 | 动效 | 时长/缓动 |
|---|---|---|
| 窗口出现 | 透明度 + 0.985→1 缩放 | 240ms `cubic-bezier(.22,1,.36,1)` |
| 导航切换 | 内容 8px 上浮淡入；离场更快 | 260ms / 160ms |
| 启动序列 | 按钮内细进度线 + 阶段文字逐级替换 + 日志逐行出现 + LED 变绿 | 阶段 320–600ms 起 |
| 就绪 LED | 3.5s 极缓呼吸（仅「可启动」时） | 无限循环（reduced-motion 关闭） |
| 数字 | 载入时 count-up 一次（≤700ms） | 仅首屏、仅一次 |
| 悬停 | 面板描边提升、行浮现操作、按钮 1px 位移 | 150–200ms |
| Toast / 菜单 / 抽屉 | 位置型：从触发方向进入 | 220–320ms |

键盘：`Esc` 关闭浮层 · `Ctrl+,` 设置 · `Enter` 触发主操作 · 全量 `:focus-visible`（铜金焦点环）。
`prefers-reduced-motion`：关闭循环与位移，全部降为淡入（不砍功能）。

## 7. 状态设计（每屏四态齐备）

- **空**：三段式（为什么空 + 下一步 + 一个动作）。例：全新机器 →「还没有数据集 · 拖入一个 YOLO 格式的数据集目录或 ZIP」。
- **载**：与终态几何一致的骨架；>5s 升级为阶段文字 + 取消。
- **错**：命名失败 + 人话原因 + 恢复动作。例：端口 8080 被占用 →「换端口 8081 重试 / 结束占用进程」。
- **部分成功**：能显示的照显，失败项就地重试（如 6 个数据集里 2 个缺 data.yaml，其余照常列出）。
- 特殊：**首启向导**（环境检测 → 默认设备 → 完成给第一个任务入口）；**训练运行中**（主控模块让位给训练卡：epoch 进度、loss、mAP、显存；提供「打开监控」）。

**修正过程（九轮，脚本存档 `_selfcheck/fix1–11.py`，均带计数断言防误伤）**：
