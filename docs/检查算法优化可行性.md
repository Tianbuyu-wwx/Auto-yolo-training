### 4. 当前使用的学习率调度器

**当前未启用任何显式学习率调度策略，使用 ultralytics 默认的线性衰减。**

关键证据：

- **`e:\项目\Auto-yolo-training\src\config_generator.py`** 第 67 行：
  ```python
  cos_lr: bool = False
  ```
  `cos_lr=False` 表示 **未启用余弦退火调度器**。

- **`e:\项目\Auto-yolo-training\src\config_generator.py`** 第 75 行：
  ```python
  lrf: float = 0.01
  ```
  `lrf=0.01` 是 **最终学习率因子**（final learning rate factor），即训练结束时学习率衰减为 `lr0 * lrf = 0.001 * 0.01 = 0.00001`。当 `cos_lr=False` 时，ultralytics 使用 **线性衰减** 从 `lr0` 衰减到 `lr0 * lrf`。

- 所有 4 个训练配置 YAML 文件中均设置：
  ```yaml
  cos_lr: false
  lrf: 0.01
  ```

- **项目中没有搜索到** `CosineAnnealingLR`、`OneCycleLR`、`StepLR`、`ReduceLROnPlateau` 等 PyTorch 原生调度器的使用。学习率调度完全委托给 ultralytics 内部机制。

- **warmup 配置**（`e:\项目\Auto-yolo-training\src\config_generator.py` 第 78-80 行）：
  ```python
  warmup_epochs: float = 3.0
  warmup_momentum: float = 0.8
  warmup_bias_lr: float = 0.1
  ```
  训练前 3 个 epoch 进行 warmup。

**总结**：当前学习率策略为 **warmup (3 epochs) + 线性衰减 (lr0 -> lr0*lrf)**，由 ultralytics 内部实现。

### 优化项：数据加载未启用缓存 / 矩形训练
- **当前状态**：`TrainingConfig` 中 `cache: False`、`rect: False`（`src/config_generator.py:58,66`），且生成的 4 个 YAML 配置也均为 `cache: false`、`rect: false`（如 `configs/train/cabel-damage-mini_auto.yaml:16,24`）。Gradio UI 没有暴露这两个参数，用户无法修改。
- **潜在收益**：开启 `cache` 可避免每个 epoch 重复做解码、归一化、letterbox 等预处理，显著缩短训练周期；开启 `rect` 可减少无效 padding，降低显存占用并提升 throughput，对长条形电缆/端子图像尤为有效。
